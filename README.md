# InvestHouse

Торговая платформа в стиле криптобиржи: лендинг + веб-терминал с **настоящими** рыночными данными (Binance) и фейковой торговлей на демо-счёте.

**Что реальное:** свечной график, стакан, лента сделок, 24-часовые тикеры по 16 парам — всё тянется напрямую из публичного API Binance через REST и WebSocket. Ключи не нужны.

**Что фейковое:** баланс, ордера и история. На бирже ничего не исполняется, деньги со счёта никто не списывает — всё хранится в localStorage браузера.

**Стек:** Node.js 20+ · Express · чистый HTML/CSS/JS (без сборки) · `fetch` + `WebSocket` в браузере · свечной график на canvas · Server-Sent Events на лендинге для симулированных котировок.

## Запуск

```bash
npm install
npm run dev     # режим разработки: сервер перезапускается при изменении файлов (node --watch)
npm start       # продакшен
npm test        # тесты API
```

- http://localhost:3000 — лендинг (реклама, калькулятор, FAQ).
- http://localhost:3000/terminal — биржевой терминал с реальными данными.
- `?symbol=BTCUSDT` — предвыбранная пара.

Переменные окружения: `PORT` (по умолчанию 3000), `TICK_MS` — интервал симулятора котировок для лендинга (1000).

## Как терминал получает реальные данные

Браузер напрямую обращается к публичным эндпоинтам Binance:

| Что | Эндпоинт |
|---|---|
| свечи (все таймфреймы 1m–1D) | `GET https://api.binance.com/api/v3/klines` |
| стакан (топ-20 bids/asks) | `GET /api/v3/depth` и WS-поток `<pair>@depth20@100ms` |
| лента сделок | `GET /api/v3/trades` и WS-поток `<pair>@aggTrade` |
| 24-часовой тикер | `GET /api/v3/ticker/24hr` и WS-поток `!miniTicker@arr` |
| живой апдейт свечи | WS-поток `<pair>@kline_<tf>` |

Домены-фолбэки на случай блокировки: `api.binance.com → data-api.binance.vision → api.binance.us` для REST, `wss://stream.binance.com:9443 → wss://stream.binance.com → wss://data-stream.binance.vision` для WS. CSP открывает только эти хосты.

Если ни один из доменов недоступен из вашей сети — на графике появится баннер «Не удалось загрузить график». Разблокируйте Binance в своей сети или сконфигурируйте локальный прокси.

## Терминал: что умеет

- 16 спотовых пар к USDT (BTC, ETH, SOL, BNB, XRP, DOGE, ADA, LTC, LINK, DOT, AVAX, ATOM, TRX, TON, NEAR, SHIB) — сортированы по объёму
- Свечной график: 1m / 5m / 15m / 1h / 4h / 1D, перекрестие с OHLC-данными
- Стакан: топ-20 bids/asks, визуализация объёма, клик по уровню — ставит цену в лимитный ордер
- Лента сделок: цвет по направлению тейкера (зелёный — покупка, красный — продажа)
- Фейковые маркет- и лимит-ордера на покупку/продажу
- Процентные кнопки 25/50/75/100% от баланса
- Открытые ордера, история сделок, балансы — три вкладки внизу
- Лимитные ордера исполняются автоматически, когда рыночная цена пересекает лимит
- Комиссия 0.1% с каждой сделки (как у Binance Spot для фиата)
- Стартовый баланс: 10 000 USDT

Весь счёт хранится в `localStorage` под ключом `investhouse.exchange.v2`. Кнопка «Сбросить» в хедере обнуляет его.

## Структура

```
server.js            Express: API + статика + CSP, пропускающий Binance
src/market.js        симулятор котировок для лендинга (минутные свечи, bid/ask, 24ч)
public/index.html    лендинг (рынки, преимущества, счета, калькулятор, FAQ)
public/terminal.html биржевой терминал (реальные данные, фейковая торговля)
public/js, css       клиентский код и стили
```

### Серверные эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/markets` | симулированные котировки для лендинга |
| GET | `/api/candles/:symbol?limit=200` | симулированная история свечей для лендинга |
| GET | `/api/stream` | SSE-поток обновлений (раз в секунду) для лендинга |
| GET | `/api/health` | проверка работоспособности |
| GET | `/terminal`, `/exchange` | биржевой терминал |

## Автодеплой

Workflow `.github/workflows/deploy.yml`: на каждый пуш в `main` прогоняются тесты, затем проект деплоится на сервер по SSH и перезапускается через PM2 (`ecosystem.config.js`).

Один раз на сервере: установить Node.js 22 и git. В репозитории GitHub → Settings → Secrets and variables → Actions добавить:

- `SSH_HOST`, `SSH_USER`, `SSH_KEY` (приватный ключ) — обязательно
- `SSH_PORT`, `APP_DIR` — по желанию (по умолчанию `22` и `~/investhouse`)

Если репозиторий приватный, добавьте на сервере deploy key (GitHub → Settings → Deploy keys) и один раз склонируйте проект в `APP_DIR` по SSH вручную. Пока секреты не заданы, шаг деплоя пропускается.

Альтернатива: есть `Dockerfile` — Render, Railway, Fly.io и подобные хостинги сами пересобирают и деплоят проект при пуше в подключённую ветку.

## Важно

- Терминал работает только когда ваша сеть имеет доступ к Binance (`api.binance.com`, `stream.binance.com`). В некоторых странах эти домены блокируются провайдерами.
- Торговля полностью демонстрационная: платформа не принимает платежей, не хранит персональных данных и не отправляет ордера на реальные биржи. Для настоящей торговли нужны бэкенд, аутентификация, подключение к бирже через API-ключ и соблюдение законодательства вашей юрисдикции.
