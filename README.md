# InvestHouse

Торговая платформа в стиле криптобиржи/брокера: лендинг + веб-терминал с котировками в реальном времени и демо-счётом.

**Стек:** Node.js 20+ · Express · чистый HTML/CSS/JS (без сборки) · Server-Sent Events для потока котировок · свечной график на canvas.

## Запуск

```bash
npm install
npm run dev     # режим разработки: сервер перезапускается при изменении файлов (node --watch)
npm start       # продакшен
npm test        # тесты API
```

Откройте http://localhost:3000 — лендинг, http://localhost:3000/terminal — терминал.

Переменные окружения: `PORT` (по умолчанию 3000), `TICK_MS` — интервал обновления котировок (1000).

## Структура

```
server.js            Express: API + статика
src/market.js        симулятор котировок (минутные свечи, bid/ask, изменение за сутки)
public/index.html    лендинг (рынки, преимущества, счета, калькулятор, FAQ)
public/terminal.html торговый терминал (график 1m/5m/15m, список рынков, BUY/SELL, позиции, история)
public/js, css       клиентский код и стили
```

### API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/markets` | список инструментов с текущими котировками |
| GET | `/api/candles/:symbol?limit=200` | история минутных свечей |
| GET | `/api/stream` | SSE-поток обновлений котировок (раз в секунду) |
| GET | `/api/health` | проверка работоспособности |

## Автодеплой

Workflow `.github/workflows/deploy.yml`: на каждый пуш в `main` прогоняются тесты, затем проект деплоится на сервер по SSH и перезапускается через PM2 (`ecosystem.config.js`).

Один раз на сервере: установить Node.js 22 и git. В репозитории GitHub → Settings → Secrets and variables → Actions добавить:

- `SSH_HOST`, `SSH_USER`, `SSH_KEY` (приватный ключ) — обязательно
- `SSH_PORT`, `APP_DIR` — по желанию (по умолчанию `22` и `~/investhouse`)

Если репозиторий приватный, добавьте на сервере deploy key (GitHub → Settings → Deploy keys) и один раз склонируйте проект в `APP_DIR` по SSH вручную. Пока секреты не заданы, шаг деплоя пропускается.

Альтернатива: есть `Dockerfile` — Render, Railway, Fly.io и подобные хостинги сами пересобирают и деплоят проект при пуше в подключённую ветку.

## Важно

- Котировки сейчас **симулированные** (`src/market.js`). Для реальных данных замените источник на API биржи/провайдера.
- Демо-счёт хранится в `localStorage` браузера. Регистрации, реальных счетов и приёма платежей пока нет — для этого нужны бэкенд с БД, аутентификация, KYC и лицензия на брокерскую деятельность в вашей юрисдикции.
